# Gallatin Demolition & Junk Removal: www.gallatindemolitionpros.com

Static site (HTML/CSS/JS) built for free hosting on GitHub Pages.

## How the site is made
All pages are generated by `tools/build.py`. **Don't hand-edit the generated HTML**; edit the source and rebuild:

| To change | Edit |
|---|---|
| Phone, business name, logo, hours, form ID, domain | `tools/config.py` |
| Demolition service pages (14) | `tools/services_demo.py` |
| Junk removal / clean-out (5) and remodel protection (4) pages | `tools/services_other.py` |
| Gallatin area pages | `tools/locations.py` |
| Spanish pages under `/es/` (home, services, 6 service pages, privacy, thank-you) | `tools/spanish.py` (wording) and `UI` in `tools/build.py` (header, footer, forms) |
| Colors / layout | `assets/styles.css` |

Then rebuild:
```
python3 tools/build.py
```
This regenerates every page, `sitemap.xml`, `robots.txt` and `CNAME`.

**Adding a new area or service:** copy an existing entry in the matching file, change the slug and text, and rebuild. Write fresh text for each area. Google penalizes location pages that are copies with only the name swapped.

- `/services/` lists every service, grouped by category

- `/service-areas/` plus 8 Gallatin area pages, e.g. `/service-areas/fairvue-plantation/`

## Hosting on GitHub Pages + Namecheap domain
1. Push this folder to its own GitHub repo (separate from Froggy Mirrors).
2. Repo → Settings → Pages → Source: deploy from branch `main`, folder `/ (root)`.
3. Custom domain: `www.gallatindemolitionpros.com` (the `CNAME` file already sets this).
4. In Namecheap → Domain List → Manage → **Advanced DNS**, delete the default parking records and add:

| Type | Host | Value |
|---|---|---|
| A Record | @ | 185.199.108.153 |
| A Record | @ | 185.199.109.153 |
| A Record | @ | 185.199.110.153 |
| A Record | @ | 185.199.111.153 |
| CNAME Record | www | froggymirrors.github.io. |

5. Wait for DNS (minutes to a few hours), then tick **Enforce HTTPS** in GitHub Pages settings.

## After launch (biggest local SEO wins)
1. **Google Business Profile**: use the exact same name, phone and city as the site, and list your services and service areas.
2. **Google Search Console**: done. Verified with `google72cfd97a97187cd6.html` in the repo root (never delete it, or verification is lost), and `sitemap.xml` is submitted.
3. **Bing Webmaster Tools**: import from Search Console.
4. Use the same name, phone and city on Yelp, Facebook, Nextdoor, BBB, Angi and Thumbtack.
5. Ask every happy customer for a Google review. Mentioning the service and neighborhood in the review helps.
6. Add real before/after job photos with descriptive names, e.g. `deck-removal-fairvue-plantation-gallatin.jpg`.

## Spanish pages
- The Spanish pages invite visitors to **text** (931) 218-3478. Nobody on the team speaks Spanish yet, so they never say "Hablamos español". If that changes, update the wording in `tools/spanish.py` and the `UI["es"]` block in `tools/build.py`.
- Quote emails from Spanish pages arrive with the subject "(SPANISH page, reply by text)". Reply by text using a translation app.
- Each Spanish page is paired with its English page in `ES_PATHS`. That pairing drives the English/Español switch and the hreflang tags Google uses to pick the right language.
- To add another Spanish service page, add its English slug to `ES_PATHS` and a full entry to `SERVICES_ES`, then rebuild.
